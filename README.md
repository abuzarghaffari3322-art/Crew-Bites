# Crew Bites

Crew Bites is a modern coffee shop landing page for a cozy café serving handcrafted coffee, desserts, and a welcoming atmosphere in Karnal Sher Khan Killi.

## Project Overview

This project is a static website built using HTML, CSS, and JavaScript. It includes a hero section, featured menu cards, an about section, and contact details with maps and WhatsApp ordering.

## Features

- Hero banner with a looping background video
- Menu showcase with item names and prices
- About Us section
- Contact section with location and WhatsApp link
- Responsive design for desktop and mobile screens

## Files

- `coffee.html` — page structure and content
- `coffee.css` — styling and layout
- `coffee.js` — interactivity and client-side behavior
- `assets/` — images, video, and other media

## Run Locally

Open `coffee.html` directly in a browser, or run a local server:

```bash
cd Crew-Bites
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/coffee.html
```
